## Request

Pursuant to Nevada's Public Records Act (NRS Chapter 239), I am requesting the following records:

### 1. Summary Eviction Case Data

All summary eviction cases filed in Washoe County Justice Courts for the period **January 1, 2020 through December 31, 2025**, including:

**From Reno Justice Court, Sparks Justice Court, and Incline Village Justice Court:**

- Case number
- Filing date
- Case type (non-payment of rent, no-cause, breach of contract, nuisance/waste)
- Property address (street address, city, zip code)
- Plaintiff name (landlord/property management company)
- Defendant name(s) - *or redacted if privacy concerns*
- Disposition (granted, denied, dismissed, settled)
- Disposition date
- Lockout order issued (yes/no)
- Lockout execution date (if applicable)

### 2. Preferred Format

Please provide data in one of the following electronic formats (in order of preference):
1. CSV (comma-separated values)
2. Excel spreadsheet (.xlsx)
3. Tab-delimited text file
4. PDF (if electronic data export is not possible)

### 3. Fee Waiver Request

We request a fee waiver or reduction under NRS 239.052 because:

1. **Public interest:** This data will be used for nonprofit research to understand housing stability issues affecting Washoe County residents and to inform tenant education programs.

2. **No commercial purpose:** The Reno-Sparks Tenants Union is a volunteer-run community organization. Data will be made publicly available to benefit the community.

3. **Journalistic/research purpose:** Analysis will be published to inform public discourse on housing policy.

If a fee waiver is not granted, please provide a cost estimate before processing so we can determine how to proceed.

### 4. Scope Clarification

If this request is overly broad or would require extensive staff time, please contact me to discuss narrowing the scope. Possible alternatives:

- Limit to cases from 2023-2025 only
- Provide aggregate monthly/quarterly counts by case type and court
- Exclude defendant names entirely
- Provide only cases with lockout orders executed

## Legal Basis

Under NRS 239.010, governmental entities must make public records available for inspection and copying. Court records, including civil case filings, are generally public unless sealed by court order.

NRS 239.0107 requires a response within 5 business days, either providing the records or a written notice of when records will be available.
