## Request

Pursuant to Nevada's Public Records Act (NRS Chapter 239), I am requesting the following records:

### 1. Code Enforcement Case Data

All code enforcement cases related to **residential rental properties** in Washoe County for the period **January 1, 2020 through December 31, 2025**, including:

**Data Fields Requested:**

- Case/complaint number
- Date complaint received
- Date of inspection
- Property address (street, city, zip)
- Property type (single-family, multi-family, apartment complex)
- Property owner name
- Property management company (if applicable)
- Violation type(s) / code section(s) violated
- Violation description
- Severity/priority level
- Compliance status (open, resolved, referred for prosecution)
- Resolution date
- Fines/penalties assessed
- Fines/penalties collected

**Violation Categories of Interest:**

- Habitability issues (plumbing, electrical, heating, structural)
- Health hazards (mold, pest infestation, sewage)
- Safety violations (fire safety, egress, security)
- Building code violations
- Occupancy violations
- Landlord/tenant disputes referred to code enforcement

### 2. Jurisdictional Note

This request covers all three jurisdictions in Washoe County:

1. **City of Reno** - Reno Code Enforcement
2. **City of Sparks** - Sparks Code Enforcement
3. **Unincorporated Washoe County** - Washoe County Code Enforcement

If separate requests are needed for each jurisdiction, please advise.

### 3. Preferred Format

Please provide data in one of the following electronic formats:
1. CSV (comma-separated values)
2. Excel spreadsheet (.xlsx)
3. Export from Accela system (if available)
4. PDF (if electronic export is not possible)

### 4. Fee Waiver Request

We request a fee waiver or reduction under NRS 239.052 because:

1. **Public interest:** This data will identify patterns of landlord neglect affecting tenant health and safety, informing community education and policy advocacy.

2. **Nonprofit use:** The Reno-Sparks Tenants Union is a volunteer community organization with no commercial purpose.

3. **Government accountability:** Publishing this data helps ensure code enforcement resources are applied equitably across all neighborhoods.

### 5. Scope Alternatives

If the full request is too broad, acceptable alternatives include:

- **Multi-family only:** Limit to properties with 4+ units
- **Recent years only:** 2023-2025 data
- **Aggregate data:** Monthly counts by violation type and zip code
- **Repeat offenders:** Properties with 3+ violations in the time period
