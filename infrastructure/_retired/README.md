# Retired infrastructure

`supabase/` is the schema and migrations of the hosted Supabase backend, retired
2026-10-26. The project it ran on no longer exists, and a backend that lives in
one person's cloud account is the single point of control the app is moving
away from. Kept for reference while the self-hostable sync node replaces it
(see `docs/notes/` for the plan). Nothing here is deployed or loaded.
